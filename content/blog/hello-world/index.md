This site now runs on [Hugo](https://gohugo.io/) with the Beautiful Hugo theme, built in Docker and deployed by GitHub Actions.
The apps — [Ptaki](/ptaki/), [Trening](/trening/) and [Peppa](/peppa/) — stay exactly where they were.

![A path through a field](path.jpg)

Images placed next to a post are converted to WebP in several sizes and served with `srcset`, so phones download a small file and big screens a sharp one.
